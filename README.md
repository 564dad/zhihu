# 洞穴小游戏（WebGL2 练手）

个人练手项目，纯手写 WebGL2 渲染，不引引擎（只用 gl-matrix 做矩阵运算，shader 手写 GLSL）。

## 跑起来

```bash
npm install
npm run dev    # 开发
npm run build  # 构建
```

## 操作

- 点击进入指针锁定，WASD 移动，空格跳，F 切换飞行（录视频用）
- 左键挖方块（基岩挖不动），右键插火把
- F3 显示调试信息：FPS、区块数、网格重建次数与单次耗时

## 实现要点

- **世界**：3×3 个 32³ 区块拼成 96×32×96，外圈 2 格基岩 + 底面封死。seed 写死在 `src/config.ts`，每次进来地形一致。地表在下，3D 值噪声掏管状洞穴 + 低频洞腔，3 口竖井从地表直通地下二层。
- **光照**：天光 / 块光两个通道各 15 级分开存。天光先按列从顶灌 15（竖直向下满级不衰减，形成光柱）再 BFS 扩散；火把 14 级点源 BFS。光照数据是整世界一张数组、BFS 队列全局，跨区块边界天然连通，不会冒黑墙/亮边；边界 2 格内的变化会把邻区块标脏重建。挖/插/拔只做增量：移除泛洪 + 边界回填，不重算全图。
- **渲染**：按区块面剔除建网格，逐顶点平滑光照（面外 4 格平均）+ 顶点 AO，所以衰减是连续渐变不是一格一格跳。火把暖色点光、天光冷色，雾密度和颜色随高度变化。火把是双面交叉面片。
- **贴图**：canvas 现画的 16px tile 图集，每 tile 四周 4px 边缘复制 padding，UV 再内缩半像素，NEAREST 采样无 mipmap，接缝不串色。
- **持久化**：挖掉的方块和火把记在 localStorage（按 seed 分 key），刷新后回放。
- **健壮性**：切标签页回来 dt 钳制不会穿墙；WebGL context lost 后自动重建全部 GL 资源，不白屏。

`window.__game` 暴露了 player/world/light/stats，调试用。
